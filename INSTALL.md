# TogglePlay Extension - Installation Guide

## Quick Installation Steps

1. **Download**: Extract the TogglePlay.zip file to a folder on your computer

2. **Open Edge Extensions**: 
   - Open Microsoft Edge browser
   - Type `edge://extensions/` in the address bar and press Enter

3. **Enable Developer Mode**:
   - Look for "Developer mode" toggle in the bottom-left corner
   - Turn it ON

4. **Load the Extension**:
   - Click "Load unpacked" button
   - Browse to and select the "TogglePlay" folder you extracted
   - Click "Select Folder"

5. **Verify Installation**:
   - You should see "TogglePlay" appear in your extensions list
   - The extension icon should appear in your browser toolbar

## Quick Start Guide

1. **Open Media Tabs**:
   - Open a YouTube video in one tab
   - Open Spotify (open.spotify.com) in another tab

2. **Create Toggle Pair**:
   - Go to either the YouTube or Spotify tab
   - Click the TogglePlay icon in your toolbar
   - The current tab will be automatically selected
   - Click on the other tab from the "Choose Second Tab" list
   - The toggle pair will be created and enabled automatically!

3. **Test It**:
   - Play a video on YouTube, then pause it
   - Your Spotify music should automatically start playing!
   - Pause Spotify, and YouTube should resume

**That's it! No more tab switching or complex setup needed.**

## Troubleshooting

- **Extension not loading**: Make sure Developer mode is enabled
- **Can't select tabs**: Only YouTube and Spotify tabs can be selected
- **Auto-toggle not working**: Check that "Enable Auto-Toggle" is turned on

For more detailed information, see README.md in the extension folder.
